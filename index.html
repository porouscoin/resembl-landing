Find the papers that read like yours.

Paste an arXiv link, upload a PDF, or search a topic. resembl finds semantically similar research, summarizes papers section by section, and answers questions with citations to the source.

Run it from GitHub → See setup steps

There's no live demo. Clone the repo and run the backend and frontend locally.

What it does

Everything you need to go from one paper to the research around it.

  1. 01

    Similar papers

    Start from keywords, an arXiv ID or your own PDF, and get the closest papers ranked by meaning, not keyword overlap.

  2. 02

    Section summaries

    Each section of a paper summarized on its own, streamed as it's written.

  3. 03

    Q&A with citations

    Ask a question about one paper or several, and the answer points back to the passages it came from, highlighted in the PDF.

  4. 04

    Clusters and network graph

    See how papers group by topic, with word clouds and a force-directed similarity graph.

  5. 05

    Trends and venues

    Publication trends over time, topic momentum, and which venues publish what.

How it works

A FastAPI backend does the analysis. A Next.js frontend shows the results.

InputarXiv ID, PDF upload or keywords
→
ExtractPyMuPDF text, spaCy + NLTK cleanup
→
Embedall-MiniLM-L6-v2 sentence embeddings
→
GroupKMeans clusters, LDA topics
→
StorePostgres + pgvector
→
AnswerLlama 3 on Groq, RAG over BGE chunks

Summary quality was checked with ROUGE and BERTScore against the papers' own sections.

Run it locally

resembl needs a database, a few local models and an LLM key, so it isn't hosted. Setting it up on your machine takes about 15 minutes.

  • Python 3.10+ and Node.js 18+
  • PostgreSQL with the pgvector extension
  • A free Groq API key in backend/.env
  • Paper data from prepare_data.py (run once)
Full setup guide on GitHub → 
# 1. get the code
git clone https://github.com/porouscoin/fyp
cd fyp

# 2. backend (http://localhost:8000)
cd backend
pip install -r requirements.txt
python -m spacy download en_core_web_sm
python prepare_data.py
python main.py

# 3. frontend (http://localhost:3000)
cd ../frontend
npm install
npm run dev

Then open localhost:3000 in your browser.
